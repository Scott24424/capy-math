# 계정 기능 구현 계획

설계: `docs/superpowers/specs/2026-09-25-accounts-design.md`

각 단계는 테스트 먼저(실패 확인) → 구현 → `npm test` 통과 → 커밋.

1. **공용 순수 로직** — `src/core/credentials.js`(normalizeEmail, isValidEmail, checkPassword),
   `src/core/merge.js`(mergeStates), `src/storage.js`에서 `validateState` export.
   테스트: `test/credentials.test.js`, `test/merge.test.js`.
2. **서버 도우미** — `api/_lib/password.js`(hashPassword, verifyPassword, safeEqual),
   `api/_lib/session.js`(createSessionToken, readSessionToken, 쿠키 문자열),
   `api/_lib/store.js`(Upstash REST 저장소 + 테스트용 memoryStore),
   `api/_lib/http.js`(본문 읽기, JSON 응답, 쿠키 파싱, 환경 읽기).
   테스트: `test/api-lib.test.js`.
3. **핸들러** — `api/_lib/handlers.js`에 `signup/login/logout/getProgress/putProgress`를
   `(req, deps)` → `{ status, body, cookie }` 순수 함수로, `api/*.js`는 Vercel 진입점 얇은 껍데기.
   테스트: `test/api-handlers.test.js`(메모리 저장소).
4. **브라우저 동기화** — `src/sync.js`: api 호출(fetchImpl 주입), 계정 캐시 읽기/쓰기.
   테스트: `test/sync.test.js`.
5. **화면** — `src/ui/screens/account.js`(로그인/가입 탭, 오류 문구), 집 화면 계정 영역,
   병합 확인 화면, 저장 대기 안내. 테스트: `test/account.test.js`(문자열 스텁).
6. **app.js 연결** — 시작 시 감지, 저장 경로 선택, 로그인/로그아웃 흐름.
7. **배포** — Vercel 환경변수·Upstash 준비 후 배포, Chrome에서 실제 확인. README·KNOWN-ISSUES 갱신.
