# 곱셈 카피바라

초등학교 3학년이 집에서 혼자 곱셈을 연습하는 프로그램입니다.

## 바로 쓰기

**https://scott24424.github.io/capy-math/**

어느 컴퓨터에서든 이 주소를 열면 바로 실행됩니다. 설치도 로그인도 필요 없습니다.

진도는 접속한 브라우저에 저장됩니다. 그래서 컴퓨터를 바꾸면 처음부터 시작하는데,
기록실 맨 아래의 **진도 내보내기 / 진도 불러오기**로 옮길 수 있습니다.
같은 컴퓨터에서 형제가 함께 쓰면 진도가 하나로 섞입니다.

## 인터넷 없이 쓰기

    npm install
    npm run build

`dist/index.html` 파일 하나를 바탕화면에 복사해 주세요. 더블클릭하면 실행됩니다.
인터넷 연결이 필요 없고, 외부로 나가는 요청도 하나도 없습니다.

## 개발

    npm run dev      # 개발 서버
    npm test         # 테스트
    npm run build    # dist/index.html 만들기

곱셈 규칙은 전부 `src/core/` 안에 있고 테스트로 덮여 있습니다.
`src/ui/`는 그리기만 합니다.

`main`에 푸시하면 GitHub Actions가 테스트를 돌리고 빌드해서 자동으로 배포합니다.
`dist/`는 저장소에 두지 않으므로 소스와 게시본이 어긋나지 않습니다.

의도적으로 남겨 둔 항목은 [docs/KNOWN-ISSUES.md](docs/KNOWN-ISSUES.md)에 정리해 두었습니다.
